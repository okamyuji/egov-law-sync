# 法令ID指定の実装順序

- 目的: `bootstrap`、`daily`、`weekly`を独立した一つの法令IDだけに限定できるようにする。
- 対象外: 複数法令IDを一つのmanifestで同期すること、週次bulk zipの転送量削減、既存Actionsの変更。
- 完了条件: 指定IDの厳密な一致、法令名・略称の一意解決、異なる対象と全件manifestの混在拒否、日次更新と週次照合の対象限定、対象別Actions、既存テストと関連テストの成功。
- 変更しないもの: 既存の全件同期、既存Actions、公開CSVの列構造。

順序: CLIの対象解決とmanifestの保存・照合 → API一覧と日次更新の対象限定 → 週次照合の集計限定 → テスト・ドキュメント・新規Actions → PRとCI・レビュー対応。

「税法」は特定の法令名ではないため、未指定時の代表法令を所得税法（`340AC0000000033`）とする。別の税法は入力の法令IDで選ぶ。週次bulk zipは全件を取得し続ける。
